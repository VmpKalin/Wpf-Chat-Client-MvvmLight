# Wpf-Chat-Client-MvvmLight

A WPF chat client (.NET Framework 4.6.1) built with MVVM Light and Material Design in XAML.

It contains login, chat and profile views. `LoginService` requests a token from `connect/token`; `SocketService` is an unfinished WebSocket stub.

## Build

Open `ChatCustomDisign.sln` in Visual Studio on Windows, restore the NuGet packages and run the project.
